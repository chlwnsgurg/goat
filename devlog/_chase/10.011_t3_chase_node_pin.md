# 10.011 — upstream Node 26.12.1 고정

> 사이클: 261022 · 상태: ⛔ needs decision
> upstream: `ed9b7ca9c` (#23165) · GOAT 영역: `cli-home` (010 참조)

## 무엇이 다른가

upstream은 루트 `package.json`의 `engines.node`를 정확한 `26.12.1`로 고정하고, 개발·CI·standalone 실행 파일이 모두 그 버전을 쓰게 했다.
`apps/server/vite.config.ts`의 `SEA_NODE_VERSION`을 지우고 `engines.node`를 읽으며, 네이티브 실행 파일 빌드는 다른 host Node를 거부한다.
`release-desktop.yml`과 `docs/operations/release.md`도 그에 맞췄다. GOAT는 `engines.node` `^24.13.1`, `SEA_NODE_VERSION` 26.8.2다.

## 결정

이번 사이클에서는 받지 않았다. 설치된 runtime은 버전으로 캐시되므로 runtime Node를 바꾸려면 새 GOAT release 버전이 필요하고, 개발자·CI·release
러너의 Node를 함께 올려야 한다. release와 함께 전용 PR로 들이는 것을 권한다.

## 할 일

release 담당 결정 뒤: `engines.node` 정확 고정, `SEA_NODE_VERSION` 제거, `release-desktop.yml`·`release.md` 반영, 러너 Node 확인.
