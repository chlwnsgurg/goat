Classify using body-free outbox resolution_id/operation kind or retained metadata, never bodies or a failed outcome alone; apply the allowlist in SQL before acquireReports LIMIT and before computing dispatch wakeups. Unknown or contradictory classification is not deliverable. No remember/edit/import/sync chatter, manual decision engine, provider task, reception/Slack route, OS notification/sound/push or synthetic run.
