## Risks and fallback placement

- Centralize alias resolution for server CLI config, `DesktopConfig`, `loadRepoEnv`, and shared observability; direct `process.env`/`HostProcess.Environment` reads also need coverage. New keys win; preserve meaningful empty/false values and configuration-source precedence.
- Extend terminal filtering (`apps/server/src/terminal/Manager.ts:1252`), desktop scrub lists and WSL forwarding to both prefixes.
- SSH ordinary shell variables are unexported, but assignments persist in `run-t3.sh`; probes parse `T3_NODE_SCRIPT_PATH`/`T3_ARCHIVE_VERSION` (`tunnel.ts:1832–1834`). Only `T3_SSH_UPLOADED_ARCHIVE` is explicitly exported; `T3CODE_NO_BROWSER` is supplied to the server (`:1438`). Preserve old parsing when renaming persisted runners.
- Installers still default to `.t3`, while SSH uses `.goat`; env fallback alone cannot prevent orphaning old data. Boot-service home parsing also recognizes only `T3CODE_HOME` (`bootService.ts:62`).
