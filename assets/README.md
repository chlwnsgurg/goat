# GOAT brand assets

Run `vp run icons:export` from the repository root to regenerate the app icons and
static mark copies. Run `vp run icons:check` to compare every generated raster,
ICO, SVG, Android vector and Icon Composer configuration without writing files.
Commit the regenerated assets with changes to the mark or channel colors.

The canonical B2 geometry lives in `packages/shared/src/goatMark.ts`. Web, mobile
and both exporters use those paths. `packages/shared/src/brandChannels.ts` defines
the flat backgrounds: stable `#18181b`, nightly `#1e1b4b`, development `#1d4ed8`.

The `.icon` Icon Composer bundles are generated inputs to native Apple builds.
Their single mark layer has glass, translucency and shadow disabled. Edit the
shared geometry or exporter rather than the bundles. The generic
`scripts/export-brand-icons.ts` remains available for native export diagnostics;
it is not the source of the committed icon pipeline.

The main exporter also owns the widget and Android notification marks and the
comment-delimited mark blocks in the DMG backgrounds. Surrounding DMG art stays
hand-authored. Android launcher foregrounds use a transparent safe-zone mark;
channel backgrounds and splash icons are generated by the Android exporter.

`assets/readme/` holds the hand-authored banner and diagram for the repository README. They copy
the mark paths from `goatMark.ts`, and `icons:export` does not regenerate them, so redraw them when
the mark changes.
